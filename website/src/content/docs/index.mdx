The documentation for Stratum, the open-source, agent-first code forge. For what Stratum is and who it is for, see
[usestratum.dev](https://usestratum.dev).

## Start here

- [Getting started](/guides/getting-started/) — from sign-up to a merged,
  evaluation-gated change: policy, agent identity, and the change flow.
- [Importing from GitHub](/guides/importing/) — bring an existing repository in and
  keep it in sync with its source.
- [CI integration](/guides/ci-integration/) — run evaluations on infrastructure you
  already have and report verdicts back.
